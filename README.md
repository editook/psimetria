# Psimetria

Proyecto de desarrollo software.

## Instalación

1. Clonar el repositorio.
2. Ejecutar `npm install` para dependencias de frontend.
3. Ejecutar `composer install` para dependencias de PHP.
4. Ejecutar `npx @tailwindcss/cli -i ./src/input.css -o ./css/tailwind.css --watch` para css Tailwind

## Tecnologías

### Frontend
- **Tailwind CSS**: Framework de CSS para el diseño de la interfaz.
- **@tailwindcss/cli**: Herramienta de compilación de Tailwind.

### Backend (PHP)
- **Dompdf**: Librería para la generación de documentos PDF desde HTML.
- **Masterminds HTML5**: Parser de HTML5.
- **Sabberworm PHP-CSS-Parser**: Parser de CSS para PHP.
